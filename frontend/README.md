# CampusHub 🎓

A modern full-stack campus management platform built for students and colleges.

## ✨ Features

- 🔐 Authentication
- 📚 Notes Sharing
- 💼 Placement Tracker
- 📅 Event Management
- 💬 Discussion Forum
- 🤖 AI Resume Review (Planned)
- 🎤 AI Mock Interview (Planned)

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

### Backend (Upcoming)
- Node.js
- Express.js
- MongoDB
- JWT Authentication
